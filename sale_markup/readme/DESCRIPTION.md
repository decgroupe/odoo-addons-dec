#  **Margin Rate** and **Markup Rate**

The two concepts look almost identical, they both talk about “margin,” and their names sound like twins.
But they measure profitability from *different angles*, which is why people mix them up all the time.

1. They talk about the same thing… from opposite perspectives

- **Margin rate**
  Based on **cost**.
  → Used by finance, accounting, and management.

- **Markup rate**
  Based on **selling price**.
  → Used by sales, retail, and pricing teams.

Because both describe profitability, people assume they’re interchangeable — they’re not.

2. Formulas look almost the same

- **Margin rate** ` = (Selling price - Cost price) / Cost price`
- **Markup rate** ` = (Selling price - Cost price) / Selling price`

Same numerator, different denominator.
And since both give percentages, it’s easy to confuse them.
