This module lets you manage software license passes that bundle multiple
application licenses under one activation serial.

- Build reusable application packs and generate passes from those packs.
- Automatically create and resynchronize underlying licenses from pack
  content.
- Control pass lifecycle (to send, sent, cancelled) with email-driven
  sending.
- Track hardware activations globally at pass level with a maximum
  allowed count.
- Navigate passes from partner records, including hierarchical
  contact/referral relationships.

Technical details
-----------------

**Pass model and lifecycle**

The model software.license.pass is implemented in
models/software_license_pass.py. It creates references via sequence,
handles state transitions, and overrides message_post to mark passes as
sent and grant portal access to recipients when the send flow is
executed.

**Pack-driven license generation**

Passes link to software.license.pack and its lines
(software.license.pack.line). The method action_resync_with_pack
compares pack lines with existing pass licenses and creates missing
software.license records, then synchronizes features from templates.

**License protection and enrichment**

The software.license model is extended in models/software_license.py
with pass ownership fields, pass-aware display name, extra export
values, and guardrails that block direct edits/deletions of pass-owned
license fields unless proper permissions/context are used.

**Hardware activation enforcement**

The pass-level activation cap is enforced through
\_check_max_allowed_hardware/check_max_activation_reached on
software.license.pass and reinforced in the software.license.hardware
create flow to keep pass consistency when hardware identifiers are
registered.

**Partner integration**

The res.partner model extension computes related passes with a
company-aware domain and exposes actions/domains to include or exclude
licenses generated by passes depending on context flags.
