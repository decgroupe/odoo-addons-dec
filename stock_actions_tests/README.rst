This module provides regression tests for ``stock_actions``.

It does not add a user-facing feature by itself. Instead, it keeps the
stock action flows covered so changes to replenishment rules, purchase
creation, and manufacturing linkage are caught early during migration
and maintenance.

- It checks make-to-order replenishment when no compatible route is
  available.
- It checks the buy flow, including the case where no vendor price is
  set.
- It checks the manufacture flow, both with and without a BoM, and the
  resulting links to production orders.

Technical details
-----------------

The module reuses the fixtures from
``stock_actions.tests.common.TestStockActionCommon`` and adds the
warehouse buy and manufacture routes in ``tests/common.py``.

``tests/test_stock_action.py`` builds make-to-order customer moves and
exercises ``action_confirm()`` under several route combinations. The
assertions cover the expected ``UserError`` messages, the
``is_cancellable`` UI flag, purchase line creation, and the production
move generated by the manufacture route.
