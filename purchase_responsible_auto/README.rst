Automatically replace or set responsible on quotation print.

When document is automatically generated, it is important to have the
right responsible assigned. This module ensures that when a quotation is
printed, if the responsible is still the default one (the one with login
"root"), it will be replaced by the user who prints the quotation. This
way, the responsible will be correctly set without relying on users to
manually change it before printing.
