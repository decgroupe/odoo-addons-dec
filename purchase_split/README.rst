Usage
=====

Open a purchase order in draft, sent or to approve state, select some
lines and click on the "Split Order" button.

A new view will open with all the lines of the order and a checkbox to
select the lines to move to a new order. Once selected, click on "Split"
from the action menu to start the wizard.

You can finally choose to select an existing draft order that will
receive the selected lines or let the system create a new one. In both
cases, the selected lines will be moved to the target order and the
original order will keep the remaining lines.
