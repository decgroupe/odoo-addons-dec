Shortcut to main seller/supplier for ``product.template`` model. Main
supplier for ``product.product`` variant model is provided by OCA module
``product_main_supplierinfo``.

Since working with the template model is not supported by Odoo, methods
with the same names have been reimplemented.

**This is a reimplementation of the existing feature from OpenERP 6.1**
